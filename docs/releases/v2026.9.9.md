# v2026.9.9

First CalVer release. Plugin version is `2026.9.9` (Git tag `v2026.9.9`). Replaces `0.1.0`.

## Added

- Four capture modes: Monitor, Follow focused window, Window, Custom
- Follow filters: All, Allowlist, Denylist
- Allowlist **WAITING** when no listed window exists (does not capture the whole monitor)
- Audio to capture (none / desktop / window) plus a Microphone toggle, including microphone-only
- Save clip, Open clips, last-save copy, and Omacut
- Settings groups: Replay, Recording region, Encoder
- `omarchy-shell io.github.anthonyposchen.instant-replay` commands: save, start, stop, toggle, open, show, close, hide, refresh

## Changed

- Status is Recording, Waiting, or Disabled. There is no Armed idle state.
- Switching to Window while already on keeps the buffer running on the pin.

## Fixed

- Allowlist no longer keeps encoding the monitor after you switch back with no listed window
- Window mode no longer turns itself off and refuses to start after a mode switch
- Omacut opens the last clip instead of an empty picker
